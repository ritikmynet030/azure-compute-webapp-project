# 🌐 Azure App Service – Web App Deployment

This lab demonstrates how to deploy a **Web Application using Azure App Service**.  
It showcases Platform as a Service (PaaS) capabilities without managing servers.

---

## 🔹 What is Azure App Service?
Azure App Service is a **fully managed PaaS** for hosting web apps, REST APIs, and backends.

---

## 🔹 Key Highlights
- No VM management required
- Built-in scaling & security
- Fast deployment
- Cost-effective for small apps

---

## 🔹 Outcome
Successfully deployed a web app accessible via a **public Azure URL**.
